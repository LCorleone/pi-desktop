# Pi Desktop v1.9.1 — Security Hardening & Chat Polish 🔒

A full security pass over the webview and IPC surface plus a visual-audit round on the conversation UI. The XSS-to-RCE chain (null CSP + `withGlobalTauri` + recursive home fs write) is closed, long code lines scroll again, and the context-usage ring no longer shows 96% when you've used 1%.

> **Note:** This is a personal fork of [`gustavonline/pi-desktop`](https://github.com/gustavonline/pi-desktop).

---

## 🎯 The headline

A code review found that a crafted markdown link could escalate to arbitrary file writes: there was no CSP, `withGlobalTauri` exposed the full Tauri API to the webview, and fs write scope covered all of `$HOME`. v1.9.1 breaks that chain at every link — CSP enforced, shell opens restricted to http(s), dangerous markdown URLs stripped, and the Rust command surface narrowed — while keeping everyday workflows working: opening local files/folders now goes through a dedicated OS-handler command, and per-project fs write access is granted at runtime when you open a project.

---

## ✨ What's new

### Webview & fs hardening

- **CSP enforced** in `tauri.conf.json` — `script-src 'self'`, no inline scripts, `connect-src` limited to app + IPC (+ dev HMR in debug builds only).
- **`shell.open` restricted to `^https?://`** — local paths open via the new `open_path_in_default_app` Rust command instead (export-to-HTML auto-open, Packages "Open folder").
- **safe-markdown component** — markdown-rendered `javascript:`/`data:`/unknown-scheme URLs in links, images, iframes and forms are stripped after every render; http(s)/mailto/fragment/relative survive.
- **Narrowed Rust commands** — `get_session_content` canonicalizes and contains paths under the session root; `run_git_command` rejects unsafe git args (`--upload-pack`, config injection, …); title generation uses a tempfile instead of a predictable path.
- **Runtime project fs scope** — fs write capability stays scoped by default; `allow_project_fs_scope` widens read+write to a canonicalized project dir when a project becomes active (blocked: `$HOME` root, home dotfiles, `/etc`, `/usr`, …). Granted paths dedupe, and a failed grant retries on next activation rather than being silently marked granted.

### Conversation UI polish (visual audit round)

- **Code blocks scroll again** — the mini-lit templates rely on Tailwind utilities emitted from `node_modules`, which Tailwind v4 never scans; a single `@source` directive restores the scroll container, the 24rem height cap, table scroll wrappers and mono labels. Long lines are no longer silently clipped.
- **`safe-markdown-block` styles fully restored** — all ~65 stylesheet selectors migrated to `:is(markdown-block, safe-markdown-block)`; code-block backgrounds, borders and the copy button render correctly in both themes.
- **Workflow summary ellipsis works** — `min-width: max-content` was preventing the intent label from ever truncating; narrow windows now ellipsize instead of clipping the duration and caret.
- **Thinking bar width matches tool bars** — dead `max-width` override removed; the gray thinking panel and green tool panels cap at the same 64ch.
- **Keyboard focus** on the workflow summary row, modified-file chips and diff toggles (previously hover-only).

## 🐛 Bugs fixed

- **Context usage ring 100× inflation** — the backend sends `contextUsage.percent` on a 0–100 scale; the frontend treated any value ≤1 as a 0–1 fraction, so 9588/1M tokens (0.96%) displayed as **96%**. Percent-named fields are now always divided by 100.
- **IME Enter** — composing Enter (Chinese/Japanese/Korean input) no longer sends the message mid-composition.
- **Lit containers destroyed by `innerHTML = ""`** — all clear sites (including shortcuts panel) now use `render(nothing, container)`.
- **Streaming state stuck after disconnect** — cleared on RPC loss; extension dialogs supersede instead of stacking.
- **File viewer race** — stale async opens can no longer clobber a newer file (request sequencing).
- **Settings save failures silent** — errors now rethrow to a visible banner in both callers.
- **Pty lifecycle races** — scoped writer clones, remove-under-lock + kill-outside-lock, exactly-once reap via `Option::take`, reaping in both read loops; blocking fs/pty calls moved to `spawn_blocking`.
- **Frontend lifecycle leaks** — components released on re-init, workspace-pane applies queued and caught (33 sites), terminal dispose idempotent.
- **Session→project matching** — substring `includes` bug fixed (project "pi" no longer matches every session).
- **Dead code removal** — `[thinking-diag]` debug logs, legacy storage keys, unused helpers; shared `fs-paths` and `theme-variant` modules replace drifted per-file copies.
